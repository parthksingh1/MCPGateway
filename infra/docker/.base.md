Dockerfiles share one shape:

deps install the whole workspace once, with the pnpm store cached
build compile every workspace package this app depends on
runtime node:20-slim, non-root, only the built output and production deps

Builds run from the repository root so that workspace links resolve. Each app
gets its own file rather than a shared one with build args, because the
difference between them is the entrypoint and the copied paths, and that is
clearer written out than parameterised.
